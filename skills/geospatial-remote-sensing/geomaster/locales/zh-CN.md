# Geomaster

[返回技能总览](../../../../README.md) · [English](en.md) · [查看原始 SKILL](../SKILL.md)

## 1. 技能简介

综合地理空间科学技能，涵盖遥感、地理信息系统、空间分析、地球观测机器学习和30多个科学领域。支持卫星图像处理（ Sentinel、Landsat、MODIS、SAR、高光谱）、矢量和光栅数据操作、空间统计、点云处理、网络分析、云原生工作流程（ STAC、COG、行星计算机）和8种编程语言（ Python、R、 Julia、JavaScript、C + +、Java、Go、Rust ） ，包含500多个代码示例。用于遥感工作流程、GIS分析、空间机器学习、地球观测数据处理、地形分析、水文建模、海洋空间分析、大气科学和任何地理空间计算任务。

它属于“地理空间与遥感”类别，核心定位是：对地理、遥感和地球观测数据进行可靠的空间处理与分析。本说明把原始技能的技术内容整理为中文使用契约；涉及具体命令、参数或版本时，仍以[原始 `SKILL.md`](../SKILL.md)及随附文件为准。

## 2. 适合用它做什么

- 处理空间与遥感数据
- 执行坐标、栅格和矢量分析
- 输出地图与空间统计结果
- 当你已有“空间数据、影像、坐标系与分析范围”，并希望得到“地图、空间数据集或统计结果”时使用。
- 当任务需要围绕“对地理、遥感和地球观测数据进行可靠的空间处理与分析”形成可复核、可继续加工的中间产物时使用。

不建议仅因为技能名称相近就直接调用；先确认研究对象、输入格式和预期产出与本页描述一致。

## 3. 工作方式

本技能按“输入契约 → 执行 → 验证 → 交付”工作。原始指令的重点阅读路径为：`安装与配置` → `快速开始` → `核心能力与原则` → `专题说明` → `工作流程` → `最佳实践`。

1. **确认研究区域、坐标参考系、空间分辨率和时间范围。** 本技能至少需要：空间数据、影像、坐标系与分析范围。
2. **完成影像或矢量数据的质量控制、投影和预处理。** 保留关键选择、参数、筛选条件和中间结果，便于复核。
3. **执行空间统计、分类、变化检测或地理计算。** 执行重点包括：处理空间与遥感数据；执行坐标、栅格和矢量分析；输出地图与空间统计结果。
4. **输出地图、栅格、矢量、精度评估和处理记录。** 最终交付：地图、空间数据集或统计结果。
5. **交付前复核。** 检查结果是否回答原始问题，是否区分事实、推断和不确定性，是否留下足够的复现与交接信息。

## 9. 边界

- 坐标系、分辨率、重采样和空间配准错误会改变结论。
- 地图精度和遥感分类必须用独立参考数据验证。
- 敏感地理位置、个人轨迹和受限影像必须按权限处理。
- 本技能的职责是“对地理、遥感和地球观测数据进行可靠的空间处理与分析”，不能替代与任务相关的伦理、临床、法律、安全或领域专家审查。
- 外部数据、接口和模型的内容可能变化；重要结论应保存来源、访问时间和稳定标识。
