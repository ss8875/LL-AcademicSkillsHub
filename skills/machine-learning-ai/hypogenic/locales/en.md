# Hypogenic

Automated LLM-driven hypothesis generation and testing on tabular datasets. Use when you want to systematically explore hypotheses about patterns in empirical data (e.g., deception detection, content analysis). Combines literature insights with data-driven hypothesis testing. For manual hypothesis formulation use hypothesis-generation; for creative ideation use scientific-brainstorming.

## Main capabilities

- Prepare data and modeling workflows
- Train or invoke machine-learning models
- Evaluate performance, bias, and reproducibility

## Inputs

- Data, task definition, and compute constraints

## Outputs

- Models, predictions, metrics, or experiment records
