# 链邻可复现论文检索

设计并执行可复现的多来源论文检索、去重、筛选与证据留存流程。

## 主要功能

- 把研究问题拆为概念块与同义词
- 选择适配学科的数据库并注明覆盖差异
- 保存完整检索式、日期、过滤条件与命中数
- 按 DOI、标题、作者和年份分层去重
- 以预先定义的纳排标准筛选
- 输出 PRISMA 风格流转统计与可复现查询记录

## 输入

- 研究问题、数据库范围、纳排标准、日期范围

## 输出

- 检索日志、去重文献集、筛选表与流程统计
