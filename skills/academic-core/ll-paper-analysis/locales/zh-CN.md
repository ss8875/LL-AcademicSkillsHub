# 链邻论文证据分析

[返回技能总览](../../../../README.md) · [English](en.md) · [查看原始 SKILL](../SKILL.md)

## 1. 技能简介

从研究问题、理论、方法、数据、结果、创新与限制形成可追溯的论文阅读卡。

它属于“链邻学术核心能力”类别，核心定位是：用链邻原创证据工作流贯通选题、检索、精读、写作、审计与成果治理。本说明把原始技能的技术内容整理为中文使用契约；涉及具体命令、参数或版本时，仍以[原始 `SKILL.md`](../SKILL.md)及随附文件为准。

## 2. 适合用它做什么

- 记录论文身份、版本与获取方式
- 分离作者陈述、论文证据与分析者推断
- 抽取研究设计、样本、变量、方法和主要结果
- 将每项关键结论定位到页码、图表或章节
- 评估内部效度、外部效度、统计与报告风险
- 生成一页阅读卡和跨论文可比较字段
- 当你已有“论文全文或合法可用文本、分析问题”，并希望得到“带定位证据的论文阅读卡与质量评估”时使用。
- 当任务需要围绕“用链邻原创证据工作流贯通选题、检索、精读、写作、审计与成果治理”形成可复核、可继续加工的中间产物时使用。

不建议仅因为技能名称相近就直接调用；先确认研究对象、输入格式和预期产出与本页描述一致。

## 3. 工作方式

本技能按“输入契约 → 执行 → 验证 → 交付”工作。原始指令的重点阅读路径为：`工作流程` → `产出契约` → `双语说明`。

1. **明确研究目标、证据标准、责任边界和最终交付物。** 本技能至少需要：论文全文或合法可用文本、分析问题。
2. **收集并定位来源，分开事实、推断、不确定性与建议。** 保留关键选择、参数、筛选条件和中间结果，便于复核。
3. **按技能契约完成分析、写作、审计或治理任务。** 执行重点包括：记录论文身份、版本与获取方式；分离作者陈述、论文证据与分析者推断；抽取研究设计、样本、变量、方法和主要结果；将每项关键结论定位到页码、图表或章节；评估内部效度、外部效度、统计与报告风险；生成一页阅读卡和跨论文可比较字段。
4. **输出证据锚点、未决问题、质量检查和可交接产物。** 最终交付：带定位证据的论文阅读卡与质量评估。
5. **交付前复核。** 检查结果是否回答原始问题，是否区分事实、推断和不确定性，是否留下足够的复现与交接信息。

你可以直接用自然语言提出任务。一个高质量请求最好同时写清目标、输入、约束、产出格式和验收标准。

### 推荐请求模板

> 请使用“链邻论文证据分析”处理【论文全文或合法可用文本、分析问题】。目标是【写明研究目标】；请遵守【时间范围、对象范围、格式或方法约束】，输出【带定位证据的论文阅读卡与质量评估】，并列出关键步骤、证据来源、不确定性和需要人工确认的事项。

### 可直接改写的请求

- “请用 链邻论文证据分析 完成记录论文身份、版本与获取方式。我的材料是【论文全文或合法可用文本、分析问题】，结果请整理为【带定位证据的论文阅读卡与质量评估】。”
- “请先检查我提供的【论文全文或合法可用文本、分析问题】是否足够，再用 链邻论文证据分析 执行生成一页阅读卡和跨论文可比较字段；不要补造缺失信息。”
- “请把 链邻论文证据分析 的处理过程做成可复核记录，交付【带定位证据的论文阅读卡与质量评估】，同时标出假设、限制和下一步建议。”

## 6. 你需要提供

- **必需输入：**论文全文或合法可用文本、分析问题。
- **任务目标：**要回答的问题、使用场景和完成标准。
- **范围限制：**研究对象、时间范围、排除条件、语言、格式或目标期刊等。
- **已有材料：**原始数据、文献、代码、图表、协议或草稿；请说明版本及允许使用的范围。
- **交付偏好：**文件格式、字段结构、是否需要脚本、是否保留中间结果与审计记录。

如果上述信息不全，应先列出缺口并向用户确认；不能把猜测当作用户已提供的事实。

## 7. 产出

- 带定位证据的论文阅读卡与质量评估。
- 一份简明的方法与参数说明，记录关键选择、版本、过滤或排除规则。
- 一份质量检查与未决问题清单，标出不能自动确认、需要领域专家复核的部分。
- 如任务产生文件，优先保留可编辑源文件，并将派生产物与用户原始材料分开。

## 9. 边界

- 不虚构来源、元数据、研究结果、法律状态或专业结论。
- 高风险临床、伦理、法律、专利与知识产权事项必须专业复核。
- 明确缺失信息和覆盖限制，不把未核验推断写成已证实事实。
- 本技能的职责是“用链邻原创证据工作流贯通选题、检索、精读、写作、审计与成果治理”，不能替代与任务相关的伦理、临床、法律、安全或领域专家审查。
- 外部数据、接口和模型的内容可能变化；重要结论应保存来源、访问时间和稳定标识。
