# Biorxiv Database

Efficient database search tool for bioRxiv preprint server. Use this skill when searching for life sciences preprints by keywords, authors, date ranges, or categories, retrieving paper metadata, downloading PDFs, or conducting literature reviews.

## Main capabilities

- Search and screen scholarly literature
- Organize metadata and citations
- Preserve auditable search evidence

## Inputs

- Research question, keywords, and search limits

## Outputs

- Literature records, screening results, or citation data
