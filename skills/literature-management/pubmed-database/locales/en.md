# Pubmed Database

Direct REST API access to PubMed. Advanced Boolean/MeSH queries, E-utilities API, batch processing, citation management. For Python workflows, prefer biopython (Bio.Entrez). Use this for direct HTTP/REST work or custom API implementations.

## Main capabilities

- Search and screen scholarly literature
- Organize metadata and citations
- Preserve auditable search evidence

## Inputs

- Research question, keywords, and search limits

## Outputs

- Literature records, screening results, or citation data
