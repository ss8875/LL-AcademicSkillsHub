# Scvi Tools

Deep generative models for single-cell omics. Use when you need probabilistic batch correction (scVI), transfer learning, differential expression with uncertainty, or multi-modal integration (TOTALVI, MultiVI). Best for advanced modeling, batch effects, multimodal data. For standard analysis pipelines use scanpy.

## Main capabilities

- Process sequences and omics data
- Use domain databases and analysis tools
- Produce reproducible bioinformatics results

## Inputs

- Sequences, omics data, or sample metadata

## Outputs

- Analysis tables, figures, annotations, or model results
