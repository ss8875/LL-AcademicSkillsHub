# Tiledbvcf

Efficient storage and retrieval of genomic variant data using TileDB. Scalable VCF/BCF ingestion, incremental sample addition, compressed storage, parallel queries, and export capabilities for population genomics.

## Main capabilities

- Process sequences and omics data
- Use domain databases and analysis tools
- Produce reproducible bioinformatics results

## Inputs

- Sequences, omics data, or sample metadata

## Outputs

- Analysis tables, figures, annotations, or model results
