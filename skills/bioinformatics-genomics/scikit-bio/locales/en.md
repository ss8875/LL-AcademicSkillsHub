# Scikit Bio

Biological data toolkit. Sequence analysis, alignments, phylogenetic trees, diversity metrics (alpha/beta, UniFrac), ordination (PCoA), PERMANOVA, FASTA/Newick I/O, for microbiome analysis.

## Main capabilities

- Process sequences and omics data
- Use domain databases and analysis tools
- Produce reproducible bioinformatics results

## Inputs

- Sequences, omics data, or sample metadata

## Outputs

- Analysis tables, figures, annotations, or model results
