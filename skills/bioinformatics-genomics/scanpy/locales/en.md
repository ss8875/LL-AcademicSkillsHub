# Scanpy

Standard single-cell RNA-seq analysis pipeline. Use for QC, normalization, dimensionality reduction (PCA/UMAP/t-SNE), clustering, differential expression, and visualization. Best for exploratory scRNA-seq analysis with established workflows. For deep learning models use scvi-tools; for data format questions use anndata.

## Main capabilities

- Process sequences and omics data
- Use domain databases and analysis tools
- Produce reproducible bioinformatics results

## Inputs

- Sequences, omics data, or sample metadata

## Outputs

- Analysis tables, figures, annotations, or model results
