# Biopython

Comprehensive molecular biology toolkit. Use for sequence manipulation, file parsing (FASTA/GenBank/PDB), phylogenetics, and programmatic NCBI/PubMed access (Bio.Entrez). Best for batch processing, custom bioinformatics pipelines, BLAST automation. For quick lookups use gget; for multi-service integration use bioservices.

## Main capabilities

- Process sequences and omics data
- Use domain databases and analysis tools
- Produce reproducible bioinformatics results

## Inputs

- Sequences, omics data, or sample metadata

## Outputs

- Analysis tables, figures, annotations, or model results
