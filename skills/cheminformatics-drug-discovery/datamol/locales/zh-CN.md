# Datamol

[返回技能总览](../../../../README.md) · [English](en.md) · [查看原始 SKILL](../SKILL.md)

## 1. 技能简介

RDKit 的 Pythonic 包装器，具有简化的界面和合理的默认值。标准药物发现的首选，包括 SMILES 解析、标准化、描述符、指纹、聚类、3D 构象异构体、并行处理。返回本机 rdkit.Chem.Mol 对象。对于高级控制或自定义参数，直接使用rdkit。

它属于“化学信息与药物发现”类别，核心定位是：围绕分子结构、性质、相互作用和候选优先级开展计算药物发现。本说明把原始技能的技术内容整理为中文使用契约；涉及具体命令、参数或版本时，仍以[原始 `SKILL.md`](../SKILL.md)及随附文件为准。

## 2. 适合用它做什么

- 分析化学结构与性质
- 查询化学和药物数据库
- 支持候选物筛选与评估
- 当你已有“分子结构、化合物标识或筛选条件”，并希望得到“结构数据、性质预测或候选清单”时使用。
- 当任务需要围绕“围绕分子结构、性质、相互作用和候选优先级开展计算药物发现”形成可复核、可继续加工的中间产物时使用。

不建议仅因为技能名称相近就直接调用；先确认研究对象、输入格式和预期产出与本页描述一致。

## 3. 工作方式

本技能按“输入契约 → 执行 → 验证 → 交付”工作。原始指令的重点阅读路径为：`能力概览` → `安装与配置` → `工作流程` → `专题说明` → `参考资料` → `最佳实践` → `边界与问题排查` → `协同与集成`。

1. **规范化分子、靶点、测定条件和结构表示。** 本技能至少需要：分子结构、化合物标识或筛选条件。
2. **选择描述符、预测、对接、筛选或生成方法。** 保留关键选择、参数、筛选条件和中间结果，便于复核。
3. **运行计算并记录模型、参数、随机种子和适用域。** 执行重点包括：分析化学结构与性质；查询化学和药物数据库；支持候选物筛选与评估。
4. **按活性、选择性、可合成性与风险形成候选排序。** 最终交付：结构数据、性质预测或候选清单。
5. **交付前复核。** 检查结果是否回答原始问题，是否区分事实、推断和不确定性，是否留下足够的复现与交接信息。

## 9. 边界

- 计算评分和生成分子不是实验活性、安全性或成药性的证明。
- 结构标准化、质子化状态和测定条件差异会显著影响比较。
- 候选结论必须经实验验证，并遵守化学品、药物和知识产权规范。
- 本技能的职责是“围绕分子结构、性质、相互作用和候选优先级开展计算药物发现”，不能替代与任务相关的伦理、临床、法律、安全或领域专家审查。
- 外部数据、接口和模型的内容可能变化；重要结论应保存来源、访问时间和稳定标识。

## 10. 相关技能

- [Rdkit](../../rdkit/locales/zh-CN.md)：用于细粒度分子控制的化学信息学工具包。 SMILES/SDF 解析、描述符（MW、LogP、TPSA）、指纹、子结构搜索、2D/3D 生成、相似性、反应。对于具有更简单界面的标准工作流程，请使用 datamol（RDKit 的包装器）。使用 rdkit 进行高级控制、自定义清理和专用算法。
- [Molfeat](../../molfeat/locales/zh-CN.md)：ML 的分子特征化（100 多个特征化器）。 ECFP、MACCS、描述符、预训练模型 (ChemBERTa)、将 SMILES 转换为特征，用于 QSAR 和分子 ML。
- [Pytdc](../../pytdc/locales/zh-CN.md)：治疗数据共享。 AI 就绪药物发现数据集（ADME、毒性、DTI）、基准、支架分割、分子预言，用于治疗性 ML 和药理学预测。

这些技能与本技能处于相近任务域。组合使用前先划分每个技能的输入、输出和责任边界，避免重复处理或相互覆盖。
