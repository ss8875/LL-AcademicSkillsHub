# Interpro Database

用于“蛋白质工程与结构生物学”场景的 Interpro Database 技能。具体能力以原始 SKILL.md 为准；使用前应核对运行环境、外部服务与许可证状态。

## 主要功能

- 分析蛋白序列与结构
- 运行结构生物学工作流
- 评估设计结果与不确定性

## 输入

- 蛋白序列、结构或设计目标

## 输出

- 结构、评分、注释或设计候选
