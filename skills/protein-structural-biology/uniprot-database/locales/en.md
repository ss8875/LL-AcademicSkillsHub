# Uniprot Database

Direct REST API access to UniProt. Protein searches, FASTA retrieval, ID mapping, Swiss-Prot/TrEMBL. For Python workflows with multiple databases, prefer bioservices (unified interface to 40+ services). Use this for direct HTTP/REST work or UniProt-specific control.

## Main capabilities

- Analyze protein sequences and structures
- Run structural-biology workflows
- Assess design results and uncertainty

## Inputs

- Protein sequences, structures, or design goals

## Outputs

- Structures, scores, annotations, or design candidates
