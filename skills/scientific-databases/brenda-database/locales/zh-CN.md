# Brenda Database

[返回技能总览](../../../../README.md) · [English](en.md) · [查看原始 SKILL](../SKILL.md)

## 1. 技能简介

通过SOAP API访问BRENDA酶数据库。检索动力学参数（ Km、kcat ）、反应方程、生物体数据和底物特异性酶信息，用于生化研究和代谢途径分析。

它属于“科学数据库”类别，核心定位是：从专业科学数据库检索、整合和规范化可信记录。本说明把原始技能的技术内容整理为中文使用契约；涉及具体命令、参数或版本时，仍以[原始 `SKILL.md`](../SKILL.md)及随附文件为准。

## 2. 适合用它做什么

- 查询领域科学数据库
- 解析并规范化返回记录
- 保留来源、版本与查询条件
- 当你已有“标识符、关键词或数据库查询”，并希望得到“结构化数据库记录与来源信息”时使用。
- 当任务需要围绕“从专业科学数据库检索、整合和规范化可信记录”形成可复核、可继续加工的中间产物时使用。

不建议仅因为技能名称相近就直接调用；先确认研究对象、输入格式和预期产出与本页描述一致。

## 3. 工作方式

本技能按“输入契约 → 执行 → 验证 → 交付”工作。原始指令的重点阅读路径为：`能力概览` → `适用场景` → `核心能力与原则` → `输入要求` → `安装与配置` → `脚本与接口` → `实践规范` → `工作流程`。

1. **明确实体类型、标识符、数据库范围和版本日期。** 本技能至少需要：标识符、关键词或数据库查询。
2. **构造查询并记录字段、过滤器、分页和命中数。** 保留关键选择、参数、筛选条件和中间结果，便于复核。
3. **解析、规范化、去重并处理跨库标识符映射。** 执行重点包括：查询领域科学数据库；解析并规范化返回记录；保留来源、版本与查询条件。
4. **输出带来源、版本和查询记录的结构化数据集。** 最终交付：结构化数据库记录与来源信息。
5. **交付前复核。** 检查结果是否回答原始问题，是否区分事实、推断和不确定性，是否留下足够的复现与交接信息。

## 9. 边界

- 数据库记录可能滞后、缺失或彼此冲突，必须保留来源与版本。
- 跨数据库标识符不应仅靠名称模糊匹配。
- 接口配额、许可、隐私和再分发限制必须遵守。
- 本技能的职责是“从专业科学数据库检索、整合和规范化可信记录”，不能替代与任务相关的伦理、临床、法律、安全或领域专家审查。
- 外部数据、接口和模型的内容可能变化；重要结论应保存来源、访问时间和稳定标识。

这些技能与本技能处于相近任务域。组合使用前先划分每个技能的输入、输出和责任边界，避免重复处理或相互覆盖。
