# Gene Database

Query NCBI Gene via E-utilities/Datasets API. Search by symbol/ID, retrieve gene info (RefSeqs, GO, locations, phenotypes), batch lookups, for gene annotation and functional analysis.

## Main capabilities

- Query domain scientific databases
- Parse and normalize returned records
- Retain source, version, and query conditions

## Outputs

- Structured database records and provenance
