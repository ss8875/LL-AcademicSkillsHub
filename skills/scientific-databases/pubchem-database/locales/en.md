# Pubchem Database

Query PubChem via PUG-REST API/PubChemPy (110M+ compounds). Search by name/CID/SMILES, retrieve properties, similarity/substructure searches, bioactivity, for cheminformatics.

## Main capabilities

- Query domain scientific databases
- Parse and normalize returned records
- Retain source, version, and query conditions

## Inputs

- Identifiers, keywords, or database queries

## Outputs

- Structured database records and provenance
