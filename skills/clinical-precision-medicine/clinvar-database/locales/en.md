# Clinvar Database

Query NCBI ClinVar for variant clinical significance. Search by gene/position, interpret pathogenicity classifications, access via E-utilities API or FTP, annotate VCFs, for genomic medicine.

## Main capabilities

- Organize clinical and precision-medicine evidence
- Handle controlled medical data
- State applicability limits and risks

## Inputs

- Clinical question, medical data, or evidence material

## Outputs

- Evidence summaries, analysis results, or structured records
