# Clinicaltrials Database

Query ClinicalTrials.gov via API v2. Search trials by condition, drug, location, status, or phase. Retrieve trial details by NCT ID, export data, for clinical research and patient matching.

## Main capabilities

- Organize clinical and precision-medicine evidence
- Handle controlled medical data
- State applicability limits and risks

## Inputs

- Clinical question, medical data, or evidence material

## Outputs

- Evidence summaries, analysis results, or structured records
