# Clinpgx Database

Access ClinPGx pharmacogenomics data (successor to PharmGKB). Query gene-drug interactions, CPIC guidelines, allele functions, for precision medicine and genotype-guided dosing decisions.

## Main capabilities

- Organize clinical and precision-medicine evidence
- Handle controlled medical data
- State applicability limits and risks

## Inputs

- Clinical question, medical data, or evidence material

## Outputs

- Evidence summaries, analysis results, or structured records
