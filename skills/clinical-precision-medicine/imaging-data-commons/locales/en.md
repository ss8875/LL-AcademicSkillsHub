# Imaging Data Commons

Query and download public cancer imaging data from NCI Imaging Data Commons using idc-index. Use for accessing large-scale radiology (CT, MR, PET) and pathology datasets for AI training or research. No authentication required. Query by metadata, visualize in browser, check licenses.

## Main capabilities

- Organize clinical and precision-medicine evidence
- Handle controlled medical data
- State applicability limits and risks

## Inputs

- Clinical question, medical data, or evidence material

## Outputs

- Evidence summaries, analysis results, or structured records
