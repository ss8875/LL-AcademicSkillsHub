# Fda Database

Query openFDA API for drugs, devices, adverse events, recalls, regulatory submissions (510k, PMA), substance identification (UNII), for FDA regulatory data analysis and safety research.

## Main capabilities

- Organize clinical and precision-medicine evidence
- Handle controlled medical data
- State applicability limits and risks

## Inputs

- Clinical question, medical data, or evidence material

## Outputs

- Evidence summaries, analysis results, or structured records
