# Fda Database

用于“临床医学与精准医疗”场景的 Fda Database 技能。具体能力以原始 SKILL.md 为准；使用前应核对运行环境、外部服务与许可证状态。

## 主要功能

- 整理临床与精准医学证据
- 处理受控医学数据
- 标注适用边界与风险

## 输入

- 临床问题、医学数据或证据资料

## 输出

- 证据摘要、分析结果或结构化记录

## 本地使用说明

先阅读根目录 `SKILL.md` 及其引用文件，再检查目录记录中的运行环境、凭据、网络、风险与许可证状态。第三方技能的本页说明不替代上游指令。

质量状态：`cataloged`；来源类型：`pinned-third-party`。
