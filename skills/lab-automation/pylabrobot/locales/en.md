# Pylabrobot

Vendor-agnostic lab automation framework. Use when controlling multiple equipment types (Hamilton, Tecan, Opentrons, plate readers, pumps) or needing unified programming across different vendors. Best for complex workflows, multi-vendor setups, simulation. For Opentrons-only protocols with official API, opentrons-integration may be simpler.

## Main capabilities

- Plan laboratory automation steps
- Connect instruments, protocols, or experiment data
- Record execution state and failure boundaries

## Inputs

- Protocols, instrument parameters, or sample plans

## Outputs

- Automation workflows, run logs, or experiment artifacts
