# Seaborn

Statistical visualization with pandas integration. Use for quick exploration of distributions, relationships, and categorical comparisons with attractive defaults. Best for box plots, violin plots, pair plots, heatmaps. Built on matplotlib. For interactive plots use plotly; for publication styling use scientific-visualization.

## Main capabilities

- Clean and validate research data
- Perform statistical analysis and modeling
- Report effects, uncertainty, and limitations

## Inputs

- Structured data, analytical question, and statistical assumptions

## Outputs

- Analysis tables, models, figures, or reproducible reports
