# Plotly

Interactive visualization library. Use when you need hover info, zoom, pan, or web-embeddable charts. Best for dashboards, exploratory analysis, and presentations. For static publication figures use matplotlib or scientific-visualization.

## Main capabilities

- Clean and validate research data
- Perform statistical analysis and modeling
- Report effects, uncertainty, and limitations

## Inputs

- Structured data, analytical question, and statistical assumptions

## Outputs

- Analysis tables, models, figures, or reproducible reports
