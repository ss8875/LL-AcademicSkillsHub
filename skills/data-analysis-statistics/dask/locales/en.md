# Dask

Distributed computing for larger-than-RAM pandas/NumPy workflows. Use when you need to scale existing pandas/NumPy code beyond memory or across clusters. Best for parallel file processing, distributed ML, integration with existing pandas code. For out-of-core analytics on single machine use vaex; for in-memory speed use polars.

## Main capabilities

- Clean and validate research data
- Perform statistical analysis and modeling
- Report effects, uncertainty, and limitations

## Inputs

- Structured data, analytical question, and statistical assumptions

## Outputs

- Analysis tables, models, figures, or reproducible reports
