# LL-AcademicSkillsHub 首期 10 小时交付计划

## 目标

在一个连续执行周期内完成“链邻学术技能仓库”的首期本地部署版本，同时交付简体中文与英文两套用户界面和文档。首期只提供两种使用方式：

1. 从源码在本地部署；
2. 下载链邻科研AI平台。

首期不承诺 Codex、Claude Code、Cursor、Gemini、OpenClaw 等外部 Agent 兼容，不建设云端 SaaS，不将外部来源作为对外品牌架构层。

## 固定架构

```text
LL-AcademicSkillsHub / 链邻学术技能仓库
├── 学术技能分类体系
├── 科研可信与质量标准
├── 中英文技能内容
├── 本地科研运行环境
└── 科研工作流与技能目录
    ├── 源码本地部署
    └── 下载链邻科研AI平台
```

来源、许可证、社区提交和第三方内容审核只作为内部治理流程存在。

## 10 小时工作包

### H0–H1：范围冻结与工程骨架

- 建立独立 Git 仓库和主分支。
- 固定首期非目标、许可证策略和品牌术语。
- 定义技能、分类、语言、质量状态和本地运行字段。
- 建立中英文文档目录、目录数据、技能目录、站点和测试目录。

验收：

- 项目不出现“全网来源”“收录全网”“全网最全”等表述。
- 对外只出现“本地部署”和“下载链邻科研AI平台”两个入口。

### H1–H3：技能迁移与归一化

- 从链邻科研版固定技能包导入现有学术技能。
- 删除 `offer-k-dense-web` 一类外部平台广告能力。
- 将五个既有核心能力归一为链邻核心技能。
- 补充双语循证阅读、合规全文获取、FAIR 数据声明、实验记录和科研成果转专利五项缺口技能。
- 为每个技能生成独立元数据和中英文功能卡。

验收：

- 每个公开技能 ID 唯一。
- 共享模块、广告模块和规划项不计入可用技能数量。
- 每个技能都有中文和英文名称、简介、用途、输入、输出、环境、风险和状态。

### H3–H5：双语目录与内容站点

- 生成中文和英文 README。
- 生成分类目录、全部技能目录和单技能详情页。
- 建立可搜索、可筛选的本地静态站点。
- 支持中文/英文切换、分类筛选、质量状态筛选和运行条件筛选。

验收：

- 目录数量从数据自动生成，禁止手写。
- 中英文目录包含相同技能 ID 集合。
- 本地浏览器无需远程服务即可浏览。

### H5–H6.5：本地部署体验

- 实现环境诊断、启动和重新构建命令。
- 提供 PowerShell 与批处理入口。
- 使用 Python 标准库提供本地 HTTP 服务。
- 缺少复杂环境时明确推荐下载链邻科研AI平台。

验收：

- Windows 中文路径和空格路径可启动。
- 不修改全局 Python 环境。
- 不要求用户安装全部科研依赖。

### H6.5–H8：质量、安全与许可证门

- 校验技能目录、`SKILL.md`、元数据、双语内容和内部链接。
- 对 Python、JavaScript 和 Shell 脚本执行语法检查。
- 扫描明文密钥、危险下载、运行时临时安装、验证码绕过和外部平台强制广告。
- 生成第三方来源和许可证审计报告。

验收：

- 结构和双语一致性错误为零。
- 高风险技能不会被标成 Verified 或 Gold。
- 所有警告均进入机器可读审计报告。

### H8–H9：全量构建与修复

- 全量生成目录、详情页、站点和统计。
- 运行所有自动化检查。
- 修复阻断性错误并重新构建。
- 检查中英文数量、链接和页面一致性。

验收：

- 构建可重复执行。
- 第二次构建不产生非预期差异。
- 本地站点可打开并完成搜索和筛选。

### H9–H10：发布就绪与交接

- 生成发布就绪报告、质量报告和已知限制。
- 明确哪些技能是链邻核心、哪些是第三方固定快照。
- 记录平台下载地址占位符及替换位置。
- 完成最终 Git 状态和文件清单检查。

验收：

- 中文和英文首页可用。
- 全部技能出现在分类目录和本地站点。
- 本地部署入口可执行。
- 发布阻断项和非阻断项被明确区分。

## 质量状态

- `cataloged`：已进入目录，尚未完成运行验证。
- `beta`：可试用，边界条件仍在完善。
- `tested`：结构、脚本和基础行为检查通过。
- `verified`：完成依赖、安全、运行和输出检查。
- `gold`：通过真实任务对照评测和专家复核。
- `restricted`：因许可证、安全或运行条件限制而不可直接启用。

首期上线不等于所有技能都达到 `verified` 或 `gold`。状态必须反映真实证据。

## 不需要人工停点

用户已明确授权本轮连续实施。上述检查点全部通过自动化验证完成，不等待中途批准。只有真实平台下载地址、二维码和品牌原始资产缺失时保留明确占位符，不阻断代码、目录、技能和本地部署建设。
