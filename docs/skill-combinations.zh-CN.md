1. 先看顶部的研究目标与协作模式；
2. 按编号和箭头读取技能职责；
3. 查看每个节点底部的“交接”产物；
4. 用底部的研究输入、协同增益、最终产出和质量门判断是否适合你的任务；

<details id="01-frontier-radar" open>
<summary><strong>01 · 研究前沿雷达：从趋势信号到可检验选题</strong></summary>

> 把分散的新文献、引文网络和跨学科观点收束为有证据支撑的研究机会。

<p align="center">
  <a href="../assets/brand/skill-combinations/01-frontier-radar.svg">
    <img src="../assets/brand/skill-combinations/01-frontier-radar.svg" alt="研究前沿雷达：从趋势信号到可检验选题" width="100%">
  </a>
</p>

**组合使用方式：**先由 **Openalex Database** 扫描产出、作者与引文网络，交付“主题簇与时间趋势”；再由 **Parallel Web** 补充实时政策与产业信号，交付“带来源的外部信号”；再由 **Scientific Brainstorming** 生成跨学科问题连接，交付“候选研究方向”；再由 **Consciousness Council** 引入多角色专业质疑，交付“争议点与替代解释”；最后由 **链邻学术选题分析** 综合新颖性、价值与可行性，交付“可追溯选题报告”。

**输入：**研究领域、时间窗口、目标人群或技术边界<br>
**产出：**前沿主题簇、研究空白、候选问题与反证清单<br>
**协同增益：**趋势、创意与多视角质疑同步发生，避免只追热点或只凭直觉选题。<br>
**质量门：**区分增长趋势与真实空白；保存检索日期、查询条件和反方证据。

**组合技能：**

- [Openalex Database](../skills/literature-management/openalex-database/locales/zh-CN.md)：扫描产出、作者与引文网络 → `主题簇与时间趋势`

- [Scientific Brainstorming](../skills/research-methods/scientific-brainstorming/locales/zh-CN.md)：生成跨学科问题连接 → `候选研究方向`

<details id="02-reproducible-search" open>
<summary><strong>02 · 可复现系统检索：从概念块到可审计文献池</strong></summary>

> 把研究问题转化为跨数据库可复查、可去重、可筛选的检索流水线。

<p align="center">
  <a href="../assets/brand/skill-combinations/02-reproducible-search.svg">
    <img src="../assets/brand/skill-combinations/02-reproducible-search.svg" alt="可复现系统检索：从概念块到可审计文献池" width="100%">
  </a>
</p>

**组合使用方式：**先由 **链邻可复现论文检索** 设计概念块与可复现检索协议，交付“查询式与纳排口径”；再由 **Pubmed Database** 执行医学 MeSH 与布尔检索，交付“医学题录记录”；再由 **Biorxiv Database** 补充生命科学预印本，交付“前沿预印本记录”；最后由 **Research Lookup** 路由其他学科与实时来源，交付“跨库补充记录”。

**输入：**PICO/研究问题、同义词、纳排标准、日期范围<br>
**产出：**完整检索式、去重文献池、筛选日志与 PRISMA 流转统计<br>
**协同增益：**数据库覆盖与检索决策被完整记录，后续综述可重跑、可解释。<br>
**质量门：**保留每库命中数、查询式和日期；数据库未检出不得表述为证据不存在。

**组合技能：**

- [链邻可复现论文检索](../skills/academic-core/ll-paper-search/locales/zh-CN.md)：设计概念块与可复现检索协议 → `查询式与纳排口径`
- [Pubmed Database](../skills/literature-management/pubmed-database/locales/zh-CN.md)：执行医学 MeSH 与布尔检索 → `医学题录记录`
- [Biorxiv Database](../skills/literature-management/biorxiv-database/locales/zh-CN.md)：补充生命科学预印本 → `前沿预印本记录`
- [Research Lookup](../skills/literature-management/research-lookup/locales/zh-CN.md)：路由其他学科与实时来源 → `跨库补充记录`

<details id="03-fulltext-evidence-reading" open>
<summary><strong>03 · 合法全文精读：从论文定位到双语证据卡</strong></summary>

> 合法获得全文，完成中英文术语对齐和可定位的证据抽取。

<p align="center">
  <a href="../assets/brand/skill-combinations/03-fulltext-evidence-reading.svg">
    <img src="../assets/brand/skill-combinations/03-fulltext-evidence-reading.svg" alt="合法全文精读：从论文定位到双语证据卡" width="100%">
  </a>
</p>

**组合使用方式：**先由 **链邻合法全文获取** 通过合规路径定位全文，交付“合法全文与获取记录”；再由 **Pdf** 提取正文、表格与页码锚点，交付“结构化全文内容”；再由 **Markitdown** 转换为可检索 Markdown，交付“保留标题层级的文本”；再由 **Bgpt Paper Search** 补充全文实验字段，交付“方法与样本结构数据”；再由 **链邻双语全文证据精读** 对齐中英文术语与证据，交付“双语证据锚点”；最后由 **链邻论文证据分析** 形成问题—方法—结论证据卡，交付“可追溯论文分析”。

**输入：**题录、DOI、研究问题与需要核验的主张<br>
**产出：**全文来源记录、双语术语表、论文证据卡与可复用笔记<br>
**协同增益：**从“读过摘要”升级为对方法、数据、结果和限制都有锚点的全文证据。<br>
**质量门：**不绕过访问控制；页码、图表和原文位置必须可回查；推断与原文分开。

**组合技能：**

- [链邻合法全文获取](../skills/academic-core/ll-lawful-fulltext-acquisition/locales/zh-CN.md)：通过合规路径定位全文 → `合法全文与获取记录`
- [Pdf](../skills/document-data-tools/pdf/locales/zh-CN.md)：提取正文、表格与页码锚点 → `结构化全文内容`
- [Markitdown](../skills/document-data-tools/markitdown/locales/zh-CN.md)：转换为可检索 Markdown → `保留标题层级的文本`
- [Bgpt Paper Search](../skills/literature-management/bgpt-paper-search/locales/zh-CN.md)：补充全文实验字段 → `方法与样本结构数据`
- [链邻双语全文证据精读](../skills/academic-core/ll-bilingual-evidence-reader/locales/zh-CN.md)：对齐中英文术语与证据 → `双语证据锚点`
- [链邻论文证据分析](../skills/academic-core/ll-paper-analysis/locales/zh-CN.md)：形成问题—方法—结论证据卡 → `可追溯论文分析`

<details id="04-review-citation-loop" open>
<summary><strong>04 · 综述与引用闭环：从证据综合到零断链参考文献</strong></summary>

> 把系统检索结果组织为主题证据，并保证正文引文与参考文献逐项一致。

<p align="center">
  <a href="../assets/brand/skill-combinations/04-review-citation-loop.svg">
    <img src="../assets/brand/skill-combinations/04-review-citation-loop.svg" alt="综述与引用闭环：从证据综合到零断链参考文献" width="100%">
  </a>
</p>

**组合使用方式：**先由 **Open Notebook** 组织全文、笔记与主题材料，交付“可检索研究知识库”；再由 **Literature Review** 综合主题、方法与证据差异，交付“证据矩阵与综述结构”；再由 **Citation Management** 核对题录并生成规范引用，交付“标准化 BibTeX”；再由 **Pyzotero** 同步集合、标签与附件，交付“可维护文献库”；最后由 **链邻学术引用审计** 校验正文与参考文献一致性，交付“缺失、错配与修复清单”。

**输入：**去重文献池、证据卡、目标综述范围与引用格式<br>
**产出：**证据矩阵、综述初稿、Zotero 文库与引用审计报告<br>
**协同增益：**证据综合、文献资产管理和引用核验不再是三个割裂步骤。<br>
**质量门：**DOI、作者、年份和页码必须核验；不得用二手引文替代原始来源。

**组合技能：**

- [Open Notebook](../skills/document-data-tools/open-notebook/locales/zh-CN.md)：组织全文、笔记与主题材料 → `可检索研究知识库`
- [Literature Review](../skills/literature-management/literature-review/locales/zh-CN.md)：综合主题、方法与证据差异 → `证据矩阵与综述结构`
- [Citation Management](../skills/literature-management/citation-management/locales/zh-CN.md)：核对题录并生成规范引用 → `标准化 BibTeX`
- [Pyzotero](../skills/literature-management/pyzotero/locales/zh-CN.md)：同步集合、标签与附件 → `可维护文献库`
- [链邻学术引用审计](../skills/academic-core/ll-citation-audit/locales/zh-CN.md)：校验正文与参考文献一致性 → `缺失、错配与修复清单`

<summary><strong>05 · 实时证据核验：把最新信息变成可用而不过度外推的结论</strong></summary>

> 对快速变化的科研信息进行实时查找、交叉核验和情景压力测试。

<p align="center">
  <a href="../assets/brand/skill-combinations/05-live-evidence-verification.svg">
    <img src="../assets/brand/skill-combinations/05-live-evidence-verification.svg" alt="实时证据核验：把最新信息变成可用而不过度外推的结论" width="100%">
  </a>
</p>

**组合使用方式：**先由 **Perplexity Search** 捕获最新研究与公开信息，交付“带引文的实时答案”；再由 **Research Lookup** 切换学术检索后端复核，交付“独立来源与论文记录”；再由 **Scientific Critical Thinking** 评估偏倚、设计与证据等级，交付“可信度与缺陷清单”；最后由 **What If Oracle** 测试边界条件和替代情景，交付“条件分支与失效场景”。

**输入：**待核验主张、时间边界、证据强度要求与决策场景<br>
**产出：**来源对照表、证据等级、冲突解释与条件化结论<br>
**协同增益：**速度由实时搜索提供，可信度由批判评估和情景分析兜底。<br>
**质量门：**至少交叉核验关键主张；标注访问日期；相关性不得写成因果。

**组合技能：**

## 02 · 研究设计与项目治理

<details id="06-hypothesis-to-study-plan" open>
<summary><strong>06 · 假设到研究方案：让好想法真正可检验</strong></summary>

> 把观察或创意转化为机制假设、可证伪预测、分析计划和正式方案。

<p align="center">
  <a href="../assets/brand/skill-combinations/06-hypothesis-to-study-plan.svg">
    <img src="../assets/brand/skill-combinations/06-hypothesis-to-study-plan.svg" alt="假设到研究方案：让好想法真正可检验" width="100%">
  </a>
</p>

**组合使用方式：**先由 **Hypothesis Generation** 构建机制假设与可证伪预测，交付“假设树与预测”；再由 **Scientific Critical Thinking** 识别混杂、偏倚和替代解释，交付“威胁清单”；再由 **Statistical Analysis** 定义效应、样本和分析策略，交付“预分析计划”；再由 **Denario** 编排数据分析到论文的研究链，交付“可执行研究工作流”；最后由 **Research Proposal** 组织为规范研究方案，交付“完整 proposal”。

**输入：**研究观察、已有证据、目标变量、资源限制<br>
**产出：**假设树、实验或观察设计、统计分析计划与研究方案<br>
**协同增益：**把“想研究什么”贯通到“怎样被数据支持或推翻”。<br>
**质量门：**预先定义终点、排除和判定规则；禁止看到结果后静默改写假设。

**组合技能：**
