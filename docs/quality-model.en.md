# Skill Quality Model

| Status | Meaning | Minimum evidence |
|---|---|---|
| `cataloged` | Indexed | Structure, metadata, bilingual profile, and static security scan pass |
| `beta` | Usable implementation | Independent workflow and boundaries exist; real-world coverage remains incomplete |
| `tested` | Tested | Fixed inputs, expected outputs, and failure cases pass in recorded environments |
| `verified` | Verified | Maintainers review consequential outputs, provenance, and domain boundaries |
| `gold` | Gold | Multi-environment regression, domain-expert review, and complete provenance/license evidence |
| `restricted` | Restricted | License, safety, privacy, ethics, or maintenance status blocks normal use |

Promotion requires additional evidence, not a label-only edit. Third-party skills begin as `cataloged`; first-party Lianlin skills begin as `beta`. Repository validation proves structure and common-risk checks only; it is not runtime validation, scientific-validity review, or legal advice.
