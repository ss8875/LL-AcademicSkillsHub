# 技能质量模型

| 状态 | 含义 | 最低证据 |
|---|---|---|
| `cataloged` | 已纳入目录 | 目录结构、元数据、双语功能卡和静态安全扫描通过 |
| `beta` | 可试用实现 | 已有独立工作流和边界说明，尚未覆盖全部真实场景 |
| `tested` | 已测试 | 在记录的环境中通过固定输入、预期输出和失败用例 |
| `verified` | 已验证 | 由维护者复核关键结果、来源和领域边界 |
| `gold` | 金标 | 多环境回归、领域专家复核、来源与许可证证据完整 |
| `restricted` | 受限 | 因许可证、安全、隐私、伦理或维护状态不建议直接使用 |

升级必须增加证据，不允许只改标签。第三方技能默认从 `cataloged` 开始；链邻原创首期从 `beta` 开始。目录验证器只证明结构和常见风险检查通过，不能替代运行测试、科学有效性验证或法律意见。
